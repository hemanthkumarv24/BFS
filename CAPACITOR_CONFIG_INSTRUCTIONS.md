/**
 * IMPORTANT: Configuration Instructions
 * 
 * Before building for production or testing with your backend,
 * update the server URL in capacitor.config.json:
 * 
 * For Development (Testing locally):
 * {
 *   "server": {
 *     "url": "http://10.0.2.2:5000",  // Android emulator
 *     // or "url": "http://192.168.x.x:5000",  // Physical device
 *     "cleartext": true
 *   }
 * }
 * 
 * For Production:
 * {
 *   "server": {
 *     "url": "https://your-actual-backend-url.com",
 *     "cleartext": false
 *   }
 * }
 * 
 * You can also use environment variables:
 * - Set VITE_API_URL in .env file
 * - The example services will use this automatically
 * 
 * Example .env file:
 * VITE_API_URL=https://your-backend-url.com
